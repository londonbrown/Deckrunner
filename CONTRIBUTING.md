# Contributing

Commit messages follow [Conventional Commits](https://www.conventionalcommits.org):

```
type(scope): summary
```

Types: `feat`, `fix`, `docs`, `build`, `ci`, `refactor`, `perf`, `test`, `chore`. Scopes are the part of the project
touched, for example `plugin`, `runtime`, `setup`, `release`, `engine`. Mark breaking changes with `!` after the type or
a `BREAKING CHANGE:` footer.

Building: see [BUILDING.md](BUILDING.md).
