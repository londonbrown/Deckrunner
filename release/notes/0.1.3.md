Skate 3's skating in Night City. Skate's own engine runs beside Cyberpunk 2077: Flick-It controls, board and skater physics, tricks, grinds, manuals, bails and session markers on Night City's streets, rails and stairs, with V riding in third person.

Deckrunner is a fork of [SK8V](https://github.com/becaring/SK8V) by becaring, built with Claude Code by a software engineer (see the README). It's an unofficial fan project, unaffiliated with EA or CD PROJEKT RED, and contains no Skate 3 or Cyberpunk 2077 code or data: a one-time setup builds everything on your PC from your own Skate 3 disc and your own game install.

## Two downloads now

- **Deckrunner-0.1.3.zip**: the plugin. Install it like any mod: Vortex, MO2, or extract it into the game folder.
- **Deckrunner-Setup-0.1.3.zip**: the one-time setup. Extract it anywhere outside the game folder and run `Deckrunner Setup.cmd`.

## Changes in 0.1.3

- The download is split into the plugin and the setup, so plugin updates install with mod managers. Setup builds the data once and no longer installs the plugin.
- Keys are configurable in `deckrunner.ini` under `[keys]`: `skate=` (Ctrl+Shift+F10) and `capture=` (Ctrl+Shift+F12).
- Developer keys are gone from release builds, including Ctrl+Shift+F2 (V's head) and Ctrl+Shift+F6 (emergency stop).
- Your settings survive updates: the plugin ships `deckrunner.default.ini` and makes `deckrunner.ini` from it only if you don't have one.
- Setup redoes a step whose files are gone instead of failing on the next one.
- Built on GitHub from source, from Deckrunner's own forks of SK8V and the repositories it uses.

## Upgrading from 0.1.2

Install **Deckrunner-0.1.3.zip** over your existing install (or with your mod manager). That's all: your data, archives and `deckrunner.ini` stay as they are, and you don't need to run setup again. If a mod manager warns that the files already exist, let it overwrite them: they were installed by the 0.1.2 setup.

## New install

1. Install [RED4ext](https://www.nexusmods.com/cyberpunk2077/mods/2380).
2. Install **Deckrunner-0.1.3.zip** (Vortex, MO2, or extract into the game folder).
3. Extract **Deckrunner-Setup-0.1.3.zip** anywhere outside the game folder and run `Deckrunner Setup.cmd`. It finds Cyberpunk 2077 (Steam or GOG) and asks for your Skate 3 disc image (`.iso`) or extracted folder. It takes a few minutes; a rerun picks up where it stopped.
   - If you don't have Python 3.11+ with numpy and Pillow, it offers to download a private copy (about 31 MB).
   - It downloads the programs it needs, each checked against its published hash: Deckrunner's setup tools (0.3 MB, from GitHub), WolvenKit's command-line tool (45 MB, from GitHub), and Microsoft's .NET 10 runtime (37 MB) if you don't have it.
4. In game: load a save and press **Ctrl+Shift+F10** to skate. Press it again to stop.

## Requirements

- Cyberpunk 2077 2.5 (PC, Steam or GOG)
- [RED4ext](https://www.nexusmods.com/cyberpunk2077/mods/2380)
- Your own Skate 3 Xbox 360 disc, as an `.iso` or extracted folder (tested: title ID 454108E6, media ID 5C087C2C, no title update)
- A gamepad (Xbox controllers, or a PS5 DualSense without Steam Input)
- About 3 GB free during setup (about 1.6 GB stays installed)

Tested with female V; male V should work but hasn't been tested yet.
