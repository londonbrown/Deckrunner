Skate 3's skating in Night City. Skate's own engine runs beside Cyberpunk 2077: Flick-It controls, board and skater physics, tricks, grinds, manuals, bails and session markers on Night City's streets, rails and stairs, with V riding in third person.

This is the same file as on [Nexus Mods](https://www.nexusmods.com/cyberpunk2077/mods/38864), where it is waiting for a manual review (Nexus holds most files with setup scripts for a moderator).

It's an unofficial fan project, unaffiliated with EA or CD PROJEKT RED. It contains no Skate 3 or Cyberpunk 2077 code or data: a one-time setup builds everything on your PC from your own Skate 3 disc and your own game install.

## Requirements

- Cyberpunk 2077 2.5 (PC, Steam or GOG)
- [RED4ext](https://www.nexusmods.com/cyberpunk2077/mods/2380)
- Your own Skate 3 Xbox 360 disc, as an `.iso` or extracted folder (tested: title ID 454108E6, media ID 5C087C2C, no title update)
- A gamepad (Xbox controllers, or a PS5 DualSense without Steam Input)
- About 3 GB free during setup (about 1.6 GB stays installed)

## Install

1. Install RED4ext.
2. Download **Deckrunner-0.1.2.zip** below and extract it anywhere outside the game folder. It isn't a drop-in mod, so don't install it with Vortex or MO2.
3. Run **`Deckrunner Setup.cmd`**. It finds Cyberpunk 2077 (Steam or GOG) and asks for your Skate 3 disc image or extracted folder. It takes a few minutes, and a rerun picks up where it stopped.
   - If you don't have Python 3.11+ with numpy and Pillow, it offers to download a private copy (about 31 MB).
   - It downloads the programs it needs, each checked against its published hash: Deckrunner's setup tools (0.3 MB, from this repository's releases), WolvenKit's command-line tool (45 MB, from GitHub), and Microsoft's .NET 10 runtime (37 MB) if you don't have it.
4. In game: load a save and press **Ctrl+Shift+F10** to skate. Press it again to stop.

To uninstall, run `Deckrunner Uninstall.cmd`.

Tested with female V; male V should work but hasn't been tested yet.

## Changes in 0.1.2

- Setup no longer uses PowerShell: `Deckrunner Setup.cmd` runs a Python setup script with Windows' own dialogs. Nothing else changed.
